# Tools index

Written November 11, 2026; updated November 12. Run everything from the game folder.

## Everyday

| Tool | Use |
|---|---|
| `setup_nathan.py` | The first install, on any machine: checks, save backup, recomp patches, CotM extraction, bootstrap, recompile (first time), content-folder install with header, then `build_nathan.py --assets --install`. Skips finished steps. |
| `make_nathan_release.py` | Packs `../dist/Nathan_Graves_<date>.zip` from an allowlist; refuses game-format files, large files, excluded folders and local paths. |
| `cotm_extract.py` | Reads the user's CotM ROM into `../build/cotm` (sprites, effects, Nathan's 22 sounds via agbplay); records the ROM path. |
| `nathan_paths.py` | Where the CotM extraction and ROM are; `CodeImage` (recorded game code reads). |
| `shield_rod.py` | Alucard's Shield Rod, package 19: `--disc <SotN cue>` records the user's SotN disc, `--validate` rebuilds three native club sprites from it, `build` / `install` make the package and the Chapter 8 Hard boss-chest edit. Settings in `../shield_rod.json`; plan in `../docs/SHIELD_ROD_PLAN.md`. |
| `refectio.py` | Shanoa's Refectio glyph, package 20: `build`, `header` (writes `src/refectio_balance.h`), `install` (package + Chapter 7 purple/boss chests), `chests [--test-weight N]`, `verify`, `uninstall`. Settings in `../refectio.json`; the heal-over-time code is `src/refectio.cpp`. The package defaults to the ring and smoke sprites generated by `refectio_fx.py`. Add `--ooe ROM.nds` to `build` or `install` to import the original art from a supported USA Order of Ecclesia ROM. |
| `arma_custos.py` | Shanoa's Arma Custos (Catacombs package 10): `add_to_package()` is called by `catacombs_dlc.py build` (glyph table, text, boss-chest drop, OoE head art when the ROM is recorded); `header` writes `src/arma_custos_balance.h`, `preview` renders the art, `--ooe <rom>` records the ROM. Settings in `../arma_custos.json`. |
| `sotn_disc.py` | Reads files from the user's SotN USA disc image (`ls`, `get`, `spells` prints the Shield Rod spell table from DRA.BIN). |
| `make_nathan_package.py` | One-off bootstrap: creates Nathan's package from the user's own Simon (8-bit) DLC (clone, name, code module from the patch list, whip, menu portraits). Run once before the first build; `--out` for a test folder. |
| `build_nathan.py` | One command: card data, all verifiers, equipment permissions, runtime build. `--assets` first rebuilds sprites, sounds and card icons; `--install` also installs both copies, the table edits and the equipment permissions. |
| `install_nathan_dss.py` | `--source` / `--active` install with a backup; `--restore <backup folder>` undoes one install. |
| `nathan_cards.py` | Builds card items, text, chest ranks and the balance header from `../nathan_dss_balance.json`. `--migrate-save` is the old test-save grant (closed game, backed up). |
| `nathan_card_drops.py` | All native table edits: enemy card drops, boss-chest cards (base and DLC stages), Nathan's Tackle row in the base Martial Arts table and its text in the base text files. `--install`, `--active`, `--verify`. |
| `nathan_dss_balance.py` | Imported by the card builder; generates `src/nathan_dss_balance.h`. |
| `verify_nathan_dss.py`, `verify_nathan_mp_balance.py`, `verify_nathan_equipment.py` | The three checks `build_nathan.py` runs. |
| `build_nathan_technical_report.py`, `build_tu3_feasibility_report.py` | Regenerate the HTML reports in `../docs`. |

## Data outside the tools

- `../originals/`: pristine copies of every game file the table tools edit (taken from the first backup of each before the backups were pruned, November 12). Game-derived: never distribute.
- `../art/dive_kick/`: the user's hand-made dive kick poses, palette-matched at build time by `nathan_rom_animations.py`.
- `../backups/`: the newest install backup of each kind, the equipment-tool backups and the save backups. Older ones were pruned November 12 (9.7 GB to about 0.2 GB).

`legacy/`: the one-off tools that first built the character from Simon's package (`make_testchar.py`, `rename_testchar.py`, `unshadow_testchar.py`, plus test helpers). Removed in the November 12 cleanup, then restored from the session transcript because the distributable recipe needs them as the record of those steps. The sheet2hod mapping files stay removed (the sprite comes from the ROM; `sheet2hod.py` stays for its packer).
