## Shared hooks (one definition, in the hub)

## Same-shard call rewrites

The code generator emits direct calls inside a shard, and LLVM may fold them to the local body, bypassing an override. `core/cmake/hodmods.cmake` rewrites these call sites to the guest dispatch table at configure time. A runtime loader that installs overrides by replacing dispatch-table entries needs the same rewrites.
